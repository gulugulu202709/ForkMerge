# ForkMerge 匿名审阅代码

当前是代码准备阶段：尚无真实视频训练、未来视频对照或方法有效性结果。77项检查是合成数据上的代码自测，不能写成77个视频实验。

两组使用相同的普通更新器、冻结生成器、64×1536记忆、数据、种子、训练次数和采样设置，只改变监督项。当前新监督是同一个未来中不同读数区域的流距离误差加权，尚不能声称构成新的擦除／保护算子。

录像检查、实际读数校准、生成器诊断与人工可见性复核通过后，才允许进入两组对照。9条校准片不进入正式测试；训练与测试另用不重叠录制。普通组本次测试全对就停止候选组，未充分训练或看不清的结果保留未决。

完整说明与CPU检查命令见[英文README](README.md)，接入流程见[中文操作说明](docs/OPERATOR_ZH.md)。本副本已将个人机器路径改为环境变量，不包含原片、权重、个人账号、凭据或服务器运维日志。
